# [[Git]]
Github is an on-line proprietary platform that has become the de-facto
standard for publishing code.
Github is not the only service that allows you to host your code, there are
many more: Bitbucket, Gitlab etc.
## **Repositories**
A github repository is a git project.
- You can clone it, push, pull to the project
- You can view the history of all commits
- You can see all branches
- You can fork it: make another repository that is a branch of the original one
## **Projects**
Github supports Kanban boards:
- You can create a project, which corresponds to a board.
- You can do the usual stuff with Kanban boards.
- You can use one board to track the activities of more than one repository
## **Issues**
An issue is a notification that anybody can send you about your code
- You can open issues to your project, in order to remember things to do
- Others can open issues to ask you to do/improve/fix things
- If the one that opens the issue attributes it to the project an issue is automatically translated into a label in the project board in the To-do column.
- You can close issues. When you think the job is done, you can close the issue. The label in the Kanban board will be moved to the Done state.
